## 📖 О проекте

Проект покрывает автотестами ключевые пользовательские сценарии интернет-магазина Demoblaze:

- 🔐 Авторизация и выход из системы
- 📝 Регистрация нового пользователя
- 🛍️ Работа с корзиной (добавление/удаление товаров, расчёт суммы)
- 💳 Оформление заказа

Тесты построены по принципу **Page Object Model** — вся логика взаимодействия со страницей инкапсулирована в соответствующих классах в `pages/`, а сами тесты содержат только бизнес-логику проверки.

## ⚙️ Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AFOKS/demoblaze_test.git
   cd demoblaze_test
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate      # macOS / Linux
   .venv\Scripts\activate         # Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Установите **Allure Commandline** (для генерации HTML-отчёта):
   ```bash
   brew install allure        # macOS
   ```
   Для других ОС — см. [официальную инструкцию](https://allurereport.org/docs/install/).

## ▶️ Запуск тестов

Запустить все тесты:
```bash
pytest
```

Запустить конкретный файл:
```bash
pytest tests/test_login.py
```

Запустить с подробным выводом:
```bash
pytest -v
```

Запустить с генерацией данных для Allure:
```bash
pytest --alluredir=allure-results
```

> 📸 При падении теста автоматически сохраняется скриншот в папку `screenshots/` с именем теста.

## 📊 Allure-отчёт

После прогона тестов с флагом `--alluredir=allure-results`:

**Быстро посмотреть отчёт (временный локальный сервер):**
```bash
allure serve allure-results
```

**Сгенерировать статический HTML-отчёт:**
```bash
allure generate allure-results -o allure-report --clean
allure open allure-report
```

В отчёте доступна иерархия **Epic → Feature → Story → Test** и подробные шаги (`@allure.step`) для каждого сценария — от открытия страницы до финальной проверки.

## ✅ Покрытие тестами

| Модуль | Тест-кейсы | Описание |
|---|---|---|
| **Логин** | LO01, LO02, LO04–LO07 | Успешный/неуспешный вход, пустые поля, выход из системы |
| **Регистрация** | SU01, SU02, SU04–SU06 | Успешная регистрация, спецсимволы в пароле, пустые поля |
| **Корзина** | C01–C04 | Добавление одного/нескольких товаров, удаление, расчёт суммы |
| **Оформление заказа** | CH01–CH03 | Успешный заказ, пустые поля, невалидная карта |

## ⚠️ Известные ограничения

- Сайт **demoblaze.com** — публичный демо-стенд без реальной валидации данных карты, месяца и года при оформлении заказа. Тест `test_checkout_invalid_card` помечен `@pytest.mark.xfail` с соответствующим пояснением: заказ успешно оформляется даже с явно некорректными данными карты, поскольку сайт не выполняет такую проверку.
- Тесты выполняются на реальном внешнем сайте, поэтому возможна флакающая нестабильность из-за сетевых задержек — таймауты ожиданий подобраны с запасом.
